每周节奏模板（按 8 小时）

时间做什么

笔记建议沿用 Obsidian 习惯：一课一页，固定四栏「概念 / 关键代码 / 踩坑 / 还没懂的问题」，用双链串起概念。

检查点：怎么算真的学会

  • 能对别人讲清一次 Agent 循环，不用翻代码
  • 能不看文档手写最小可用 Agent
  • 拿到新需求，能判断该改 prompt、加工具、换编排，还是上 RAG
  • 出 bug 能定位到「模型 / prompt / 工具 / 状态 / 检索」哪一层
  • 能用评估数据证明改进有效，而不是凭感觉

卡住时的分层定位法

  1. 环境问题 → 跑 python check_env.py
  2. 换 MockLLM 复现 → 正常则是模型 / 格式问题
  3. 打印每轮 prompt → 看记忆有没有拼对
  4. 单独测工具函数 → 排除工具实现
  5. 最后才怀疑框架

明确先不做的事

  • 不微调模型、不训练 embedding
  • 不追新框架，别背 API
  • 不一上来就多智能体
  • 不跳过手写 Agent 阶段

本环境的三个版本坑

  • mcp 2.x：FastMCP 已改名 MCPServer（mcp.server.mcpserver）
  • LangChain 1.x：initialize_agent 已移除，用 langchain.agents.create_agent
  • ChatOpenAI：需 use_responses_api=False 才走 /chat/completions

资源以官方文档为准：OpenAI 兼容协议、LangGraph、MCP(modelcontextprotocol.io)、ChromaDB、Ollama。完整文字版见 LEARNING_PATH.md。
